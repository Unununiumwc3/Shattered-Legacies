# Bot spellcasting (0.70.0): every Channel-based ability (ANcl) that a unit or hero carries needs ONE row here.
# gen_spells.py reads this file + the map data and writes Ai/AiSpells.g.cs (WL) and
# ShatteredLegacies/Bot/SlAiSpells.g.cs (abilities only fork units carry). Unlisted abilities are never cast.
#
# Columns (whitespace separated, the note runs to the end of the line):
#   id      ability id (as in mapdata/WarcraftLegacies/AbilityData)
#   kind    unit    = cast on a unit already inside cast range
#           point   = cast on a point inside cast range (AoE: where it hits the most)
#           instant = no target ("click"), cast where the caster stands
#           skip    = never cast by the bot (utility, quest, travel, sacrifice, no effect in code, ...)
#   who     enemy | ally | self   (self = point on the caster's own spot, or a self buff)
#   min     least worth inside the area, enemy or ally (unit 1, hero 3); "-" = default (3 for areas, 1 for units)
#   radius  area used to count targets; "-" = the ability's own area (aare), else 300
#   flags   "-" or: mana = prefer targets that have mana; hurt = ally target only below 70 % life
#
# Common to all (0.71.0): enemy-targeted unit / point spells in a BIG FIGHT (3+ enemy and 3+ friendly worth within
# 2000, heroes count 3); self buffs, ally spells and no-target spells already in a skirmish (1+ enemy worth within
# 2000 -- they check their own targets around the caster). Cooldown ready, enough mana, the caster neither
# channelling, travelling nor on a mission. No chasing: targets inside cast range only.
#
# 0.71.0: item-based unit abilities (base AI..., no order string) may have a row too -- kind "instant" only; the bot
# orders them by their ability id. Not listed = never cast. "instant self ... hurt" = only while the caster is
# below 70 % life; "instant ally ... hurt" = counts hurt allies only.
