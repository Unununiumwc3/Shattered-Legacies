# Content index -- what can be recycled

GENERATED by `python3 tools/shattered-legacies/content/content_index.py` (repo root, a few seconds; re-run after map
data changes). Only this README is written by hand.

The index lists every object of three sources, so nobody has to scan the map data again:

| Map | Source | Note |
|---|---|---|
| `main` | `mapdata/WarcraftLegacies/` | this map: every custom or changed object |
| `24p` | `mapdata/WarcraftLegacies24p/` | WL's 24-player map (part of WL 4.8.2). Identical copies of main objects are left out |
| `stock` | `src/War3Api.Object/Generated/1.36.0.20257/` | WC3's own objects the main map does not change. Referenced only -- their models and icons are in every WC3 install |

**Asking for content**: name the object as `<map>:<id>` -- "use `24p:u011` (Plaguetorium) for the Forsaken",
"give the draenei remnant `main:e01X`'s workers". For a quick overview by race, read `REUSE.md`; for anything else,
search the TSV files (`grep -i plaguetorium Content/units.tsv`, or open them in a spreadsheet).

## Files

| File | Rows | Columns |
|---|---|---|
| `REUSE.md` | units, heroes, buildings that are free to recycle (unused in main; 24p only / different) | id, name, kind, model source, made at, trains / builds, status |
| `units.tsv` | units, heroes, buildings | id, map, status, kind (hero / building / unit), name, suffix, base, race, model, model_src, icon, faction (main: WL's object limits), made_at (buildings / workers that train, build or sell it), trains, builds, researches, sells, abilities, requires |
| `abilities.tsv` | abilities | id, map, status, name, suffix, base, hero, item, race, icon, on (units / items that have it) |
| `upgrades.tsv` | upgrades / researches | id, map, status, name, suffix, base, race, icon, researched_at |
| `items.tsv` | items | id, map, status, name, base, class, icon, abilities, sold_at |

Lists are cut after 8-12 entries (`,+N` = N more); `-` = none.

## Status

- `main` / `stock` rows: **used** or **unused** in the main map. Used = reachable from WL's faction object limits
  (`FactionObjectLimits/*ObjectInfo.cs`), the preplaced units (and their items) or a reference in the C# code, through
  the objects' own references (trains, builds, researches, sells, abilities, upgrades, requirements, unit types in
  changed ability data). **Heuristic**: an object that is only used through a stock ability's built-in data (e.g. a
  summon nobody changed) or through triggers outside the C# code shows "unused" -- check before deleting anything.
- `24p` rows: **24p only** (the id is free in the main map), **different** (the id is taken by ANOTHER object in the
  main map), **changed** (the same object, other data -- only in the TSV files).

## Model source (`model_src`)

| Value | Meaning for a copy into the main map |
|---|---|
| `stock` | a WC3 model -- nothing to copy |
| `main` | the import already exists in the main map |
| `24p` | the import exists only in the 24p map -- copy the file (an LFS pointer; the object is already on the server) |
| `missing` | the model path points to an import that is in neither map |
